# Pro-Mantenimiento

Proyecto académico desarrollado para el curso Proyecto Tecnológico.

## Caso piloto

Condominio Nuevo Alcázar - Rímac, Lima.

## Objetivo

Desarrollar una plataforma web para mejorar la gestión de incidencias y el mantenimiento preventivo en condominios residenciales.

## Problemática

Actualmente, la gestión de incidencias en el caso piloto se realiza mediante distintos canales, incluyendo WhatsApp, portería, cuadernos físicos y archivos Excel.

La entrevista realizada al administrador del Condominio Nuevo Alcázar evidenció dificultades relacionadas con:

- pérdida de información;
- seguimiento manual de incidencias;
- falta de trazabilidad;
- dificultad para conocer el responsable y estado de cada caso;
- cierre informal de incidencias;
- falta de alertas para mantenimiento preventivo;
- historial de mantenimiento distribuido entre archivos físicos y correos.

## Stack tecnológico

- Frontend: Angular
- Backend: Spring Boot
- Base de datos: MySQL
- Autenticación: Firebase Authentication
- Gestión ágil: Jira
- Control de versiones: GitHub
